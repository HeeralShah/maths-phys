# Scope

Excerpt notes contain verbatim quotations or tightly bounded extracts with explicit locators.

# How To Use

- One excerpt note per reusable quoted passage or small bundle of related passages.
- Always link back to exactly one source note.
- Prefer embedding excerpt blocks into concept notes rather than duplicating the quote.
