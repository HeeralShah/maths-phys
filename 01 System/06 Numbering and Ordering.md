# Numbering and Ordering

This vault uses numeric prefixes so folders and notes sort in a stable order.

## General Rule

Within any active folder:

- `01` is reserved for the index note when the folder has one
- other main items are numbered upward from `02`
- special support folders that should stay last can use high numbers

## Index Notes

If a folder represents a branch in the Atlas, its index note should normally be:

- `01 <Branch Name> Index.md`

Examples:

- [[02 Atlas/01 Atlas Index|01 Atlas Index]]
- [[02 Atlas/09 Quantum Field Theory/01 Quantum Field Theory Index|01 Quantum Field Theory Index]]
- [[02 Atlas/09 Quantum Field Theory/02 Canonical Quantization/01 Canonical Quantization Index|01 Canonical Quantization Index]]

## Source Folders

If a branch needs a provisional note area for source-driven work, use:

- `98 Source Study`

If a branch needs a local source-file folder, use:

- `99 Sources`

This keeps rough reading notes just ahead of stored source files and prevents frequent renaming as the branch grows.

## System Folder

`01 System` follows the same logic:

- `01 System Index`
- then the main handbook notes
- then `99 Templates`

## When To Renumber

Renumber only when it materially improves navigation.

Good reasons:

- an index note is no longer first
- a branch has grown enough to need a stable reading order
- a special support folder needs to stay at the end

Bad reasons:

- cosmetic renumbering with no navigational benefit
- forcing arbitrary order onto notes that are still exploratory
