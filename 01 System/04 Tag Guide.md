# Tag Guide

This vault uses tags as a light overlay on top of the topic hierarchy.

Folders, indices, and normal links carry the main structure. Tags should stay sparse.

## Recommended Tag Families

### Note role

- `#index`
- `#topic`
- `#proof`
- `#example`
- `#synthesis`
- `#course`

### Workflow state

- `#status/seed`
- `#status/growing`
- `#status/polished`
- `#status/review`

### Broad area

- `#area/math`
- `#area/physics`
- `#area/mixed`

### Optional level

- `#level/intro`
- `#level/intermediate`
- `#level/advanced`

## What Not To Do

- Do not encode the entire subject tree only in tags.
- Do not create a new tag for every tiny topic.
- Do not use tags when a normal wikilink or parent index is clearer.

## Topic-First Principle

- Use tags for broad filtering.
- Use indices for navigation.
- Use citations and source sections instead of source tags or source folders.

For the overall branch philosophy, see [[01 System/05 Atlas Structure|Atlas Structure]].
