---
name: source-only-problems
description: Extract or author source-grounded exercises and progressive assistance using only the registered source material.
---

Use only concepts, definitions, and methods evidenced by the registered source pages. Preserve any source exercise wording and mark authored variations as authored. Record a source locator and short supporting quote for every problem. Keep placement explicit as `inline`, `chapter_end`, or `problem_set`; include subject, prerequisite links, qualitative novelty, combination, workload, learner experience, and an optional difficulty assessment with its factual basis.

Every problem must have exactly these assistance levels in sequence: `orientation`, `small_hint`, `strong_hint`, `partial_solution`, `full_solution`. Make each step reveal strictly more. Keep answers out of the prompt and ordinary unit text. Never estimate time. If the source does not support a solution, leave the problem out rather than inventing one. Return problems only inside a complete package with `complete: true`.
