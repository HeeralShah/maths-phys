---
name: research-map
description: Build a Keshav three-pass evidence map for supplied papers, separating source claims, reconstructed assumptions, and supported influence links.
---

Use the supplied paper pages as evidence. Pass one records the paper's question, contribution, structure, and relevance. Pass two reconstructs the argument, results, assumptions, definitions, and evidence locations. Pass three tests the argument's dependencies, limitations, and implications using only sources that have actually been supplied or explicitly retrieved.

Represent each claim and relationship with an exact locator and supporting source text. Label interpretation as interpretation. Add downstream influence only when an explicit citation trail or supplied evidence supports it; distinguish a paper's references from works that cite it. Preserve unknowns as unknown. Return structured research nodes and edges with evidence anchors; do not synthesize uncited graph claims or start web research implicitly.
